The shipped app renders section headings as browser-default <h2> at 1.5em bold, which outweighs the page title. Section labels here are deliberately quieter than the thing they sit under.

Two changes from shipped. Buttons set align-self: flex-start, so they cannot stretch inside a flex column — that is the full-width green “Save Property name” bar. Disabled uses a flat token surface rather than opacity: .55, which pushed white-on-sage below AA.
