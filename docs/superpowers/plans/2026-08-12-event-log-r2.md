# Durable Event Log (R2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Archive every queue-delivered domain event to tenant-prefixed R2 segments, prove log fidelity + ARI SoR-convergence, and make `PURGE_R2` honest (org prefix-delete / guest `retained`).

**Architecture:** Worker-side writer in the existing `hospai-events` consumer: CHECK survivors → group by `source` → one NDJSON object per group → then project/MARK. Replay lists by prefix, sorts keys (lex ≡ seq), dedupes `eventId`. Org purge deletes those prefixes; guest certificates `retain` the log.

**Tech Stack:** Cloudflare Workers + R2 + Queues + Workflows, `@cloudflare/vitest-pool-workers`, existing `PurgeWorkflow`

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-12-event-log-r2-design.md` (normative); amends `docs/superpowers/specs/2026-08-12-purge-workflow-design.md` §1.1
- Mechanism: Worker `R2.put` — not Pipelines (ARCHITECTURE §4.7 two-row table + §4.8 step 4)
- Key: `events/{do}/{id}/{seqStart:020}-{seqEnd:020}-{crypto.randomUUID()}.ndjson` — nonce is **always** `crypto.randomUUID()` (not first `eventId`; that would be deterministic)
- `{do}` is only `'property' | 'org'`
- Consumer order: CHECK all → group survivors → archive per source-group → per-message project → MARK → ack
- Archive put failure: `retry()` **only that group**; do not swallow
- Replay dedupe: last-write-wins by lex-key order; log is append-only
- Certificate `status`: `'pending' | 'reached' | 'skipped' | 'retained'`
- In-scope stores start `{ status: 'pending' }` (no `deleted`, no skip/retain `reason`). Out-of-scope stores start `skipped` + reason (`iceberg` always; `r2` only when unbound)
- Each successful store step **replaces** the whole record (`replaceStore`, not merge)
- `retained` has `reason` and **no** `deleted`; `pending` has neither
- Halted `stores_json` must not contain `reached` for unattempted stores; certified `stores_json` contains no `pending`
- R2 skip **derived** from `hasEventLogR2(env)`; Iceberg stays `no_iceberg_binding`
- Guest `retained` is current-state (event log only) — not a permanent “guest R2 = retained” rule
- `isolatedStorage: false` stays (Workflows); do not run pms-core tests unsharded in CI
- No Iceberg, no new projections, no TTL, no date buckets, no `.dev.vars` for the bucket

**Locked (not a fork):** `initialStores(env)` — kind is not required; R2 depends only on binding:

| Store | Binding present | Binding absent |
|---|---|---|
| `key_store`, `property_do`, `org_do` | `{ status: 'pending' }` | `{ status: 'pending' }` |
| `r2` | `{ status: 'pending' }` | `{ status: 'skipped', reason: 'no_r2_binding' }` |
| `iceberg` | `{ status: 'skipped', reason: 'no_iceberg_binding' }` | same |

Steps **replace** the whole record on success:

- Org `purge-r2` → `{ store: 'r2', status: 'reached', deleted: n }`
- Guest `retain-r2` → `{ store: 'r2', status: 'retained', reason: 'pii_by_reference_event_log' }`
- Guest `skip-r2` (unbound) is a no-op; already skipped

`replaceStore` replaces the object (does not merge). Merging would leave leftover fields (`deleted: 0` on `retained`, or a skip reason on `reached`).

Do **not** use `skipped: purge_r2_pending`. `skipped` means out of scope; unattempted in-scope work is `pending`.

Vitest always has the wrangler R2 binding. Criterion 7 (no binding → skip) is a **unit test of `initialStores` / `hasEventLogR2`** with a stub env, not a Workflow run without wrangler.

Consumer: if `!hasEventLogR2(env)`, retry every survivor (fail closed — no projection without a log). Production/wrangler/vitest always bind the bucket.

```ts
// apps/pms-core/src/event-log.ts
import type { DomainEventMessage, EventSource } from '@hospai/contracts';

export const SEQ_PAD_WIDTH = 20;

export function padSeq(seq: number): string {
  if (!Number.isInteger(seq) || seq < 0) throw new Error(`invalid seq: ${seq}`);
  return String(seq).padStart(SEQ_PAD_WIDTH, '0');
}

export function eventLogPrefix(source: EventSource): string {
  return `events/${source.do}/${source.id}/`;
}

export function eventLogObjectKey(
  source: EventSource,
  seqStart: number,
  seqEnd: number,
  nonce: string,
): string {
  return `${eventLogPrefix(source)}${padSeq(seqStart)}-${padSeq(seqEnd)}-${nonce}.ndjson`;
}

export function sourceGroupKey(source: EventSource): string {
  return `${source.do}:${source.id}`;
}

export function groupMessagesBySource(
  messages: DomainEventMessage[],
): Map<string, DomainEventMessage[]> {
  const groups = new Map<string, DomainEventMessage[]>();
  for (const m of messages) {
    const k = sourceGroupKey(m.source);
    const list = groups.get(k);
    if (list) list.push(m);
    else groups.set(k, [m]);
  }
  for (const list of groups.values()) {
    list.sort((a, b) => a.seq - b.seq);
  }
  return groups;
}

export function serializeSegment(events: DomainEventMessage[]): string {
  return events.map((e) => JSON.stringify(e)).join('\n') + (events.length ? '\n' : '');
}

export function parseSegment(body: string): DomainEventMessage[] {
  const lines = body.split('\n').filter((l) => l.length > 0);
  return lines.map((l) => JSON.parse(l) as DomainEventMessage);
}
```

```ts
export function hasEventLogR2(env: { EVENT_LOG_R2?: R2Bucket }): boolean {
  return env.EVENT_LOG_R2 != null;
}

export async function putEventLogSegment(
  bucket: R2Bucket,
  events: DomainEventMessage[],
): Promise<string> {
  if (events.length === 0) throw new Error('empty event-log segment');
  const source = events[0]!.source;
  const seqStart = events[0]!.seq;
  const seqEnd = events[events.length - 1]!.seq;
  const key = eventLogObjectKey(source, seqStart, seqEnd, crypto.randomUUID());
  await bucket.put(key, serializeSegment(events));
  return key;
}

export async function archiveBySource(
  bucket: R2Bucket,
  messages: DomainEventMessage[],
): Promise<{ ok: DomainEventMessage[]; failed: DomainEventMessage[] }> {
  const ok: DomainEventMessage[] = [];
  const failed: DomainEventMessage[] = [];
  for (const group of groupMessagesBySource(messages).values()) {
    try {
      await putEventLogSegment(bucket, group);
      ok.push(...group);
    } catch {
      failed.push(...group);
    }
  }
  return { ok, failed };
}

export async function listEventLogKeys(bucket: R2Bucket, prefix: string): Promise<string[]> {
  const keys: string[] = [];
  let cursor: string | undefined;
  do {
    const page = await bucket.list({ prefix, cursor, limit: 1000 });
    for (const obj of page.objects) keys.push(obj.key);
    cursor = page.truncated ? page.cursor : undefined;
  } while (cursor);
  return keys;
}

export async function replayEventLog(
  bucket: R2Bucket,
  source: EventSource,
): Promise<DomainEventMessage[]> {
  const keys = (await listEventLogKeys(bucket, eventLogPrefix(source))).sort();
  const byId = new Map<string, DomainEventMessage>();
  for (const key of keys) {
    const obj = await bucket.get(key);
    if (!obj) continue;
    for (const event of parseSegment(await obj.text())) {
      byId.set(event.eventId, event); // last-write-wins in lex order
    }
  }
  return [...byId.values()].sort((a, b) => a.seq - b.seq);
}

export async function deleteEventLogPrefix(bucket: R2Bucket, prefix: string): Promise<number> {
  let deleted = 0;
  for (;;) {
    const keys = await listEventLogKeys(bucket, prefix);
    if (keys.length === 0) return deleted;
    for (let i = 0; i < keys.length; i += 1000) {
      const chunk = keys.slice(i, i + 1000);
      await bucket.delete(chunk);
      deleted += chunk.length;
    }
  }
}

export async function assertEventLogPrefixEmpty(bucket: R2Bucket, prefix: string): Promise<void> {
  const keys = await listEventLogKeys(bucket, prefix);
  if (keys.length > 0) {
    const err = new Error('verify_r2_residue');
    err.name = 'verify_r2_residue';
    throw err;
  }
}
```

`deleteEventLogPrefix` loops until list is empty so a page that filled 1000 still finishes (strong LIST: after delete, list is authoritative).
